# Launcher 0.6.3.8

* Fixed: The macOS launcher never checked for a newer version, so it could stay on an old build without saying so. Launchers older than 0.6.3.2 cannot read the version of current beta builds, so after installing one, Launch and Update stayed greyed out and the launcher said it could not detect the game version. The macOS launcher now checks for updates like the Windows and Linux ones. When a new version is out it offers to download the disk image, and Install and Update stay off until the launcher is updated. Launch keeps working

If you are on macOS with a launcher older than this one, it will not tell you about this update. Download `Ksp2Redux-macos-arm64.dmg` from the releases page and drag KSP2 Redux into Applications to replace the old one.
