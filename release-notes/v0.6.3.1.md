# Launcher 0.6.3.1

* Fixed: Switching from a URP build back to an older Redux build, such as a snapshot, failed with "Cannot apply prepatch to Redux install". The launcher keeps the bundle conversion's records through the switch, and it mistook them for an installed Redux build. The switch now goes through and puts the game's asset bundles back to stock
* Fixed: When an install fails and the launcher rolls the game back to stock, it now also undoes the bundle conversion. Before, the rolled-back game kept the converted bundles, which show up magenta in stock KSP2 and in Redux builds from before URP

If an older Redux build already shows magenta after switching from a URP build, verify the game files (Steam: Properties, Installed Files, Verify integrity of game files), then install the build again from the launcher.
