# Launcher 0.6.3.0

This update gets the launcher ready for the Redux builds that move KSP2 to Unity's Universal Render Pipeline (URP). Those builds need the game's own asset files pointed at new URP shaders, and the launcher now does that for you when it installs them. Older Redux builds install the same way as before.

## Launcher

* Added: After installing or updating to a URP build, the launcher converts the game's stock asset bundles so their materials use the URP shaders. This takes a few minutes the first time and needs about 2.5 GB of extra disk space
* Added: Uninstalling, reverting to stock or switching to an older Redux build undoes the conversion, so the game's files are back to exactly how they were
* Fixed: Uninstalling now also removes the files Redux puts in `KSP2_x64_Data/StreamingAssets/ReduxSDK`, which used to be left behind

## Command line tool

* Added: `bundles convert`, `bundles revert` and `bundles verify` to run, undo or check the conversion by hand
