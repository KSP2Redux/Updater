# Launcher 0.6.4.0

* Changed: The launcher and the command line tool now run on .NET 11. Nothing needs to be installed for it, since the runtime ships inside the download
* Changed: On macOS the launcher now needs macOS 14 (Sonoma) or later. On an older Mac, macOS says so when you open it. Every Apple Silicon Mac can update to macOS 14
* Changed: On Linux the launcher restarts itself after an update without the `setsid` command

If you are on macOS 12 or 13, keep using launcher 0.6.3.9. It does not offer this update.
