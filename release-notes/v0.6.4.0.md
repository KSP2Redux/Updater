# Launcher 0.6.4.0

* Changed: The launcher and the command line tool now run on .NET 11. Nothing needs to be installed for it, since the runtime ships inside the download
* Changed: On macOS the launcher now needs macOS 14 (Sonoma) or later. On an older Mac, macOS says so when you open it. Every Apple Silicon Mac can update to macOS 14
* Changed: On Linux the launcher restarts itself after an update without the `setsid` command

### Installing and uninstalling

* Fixed: Uninstalling Redux, or rolling back a failed install, deleted the game files before opening `uninstall.zip`. If that file was damaged, for example by a move between drives that was cut short, the game was left with no files at all. A damaged `uninstall.zip` now stops the restore before anything is deleted
* Fixed: Installing Redux on a game that was already Redux, after `uninstall.zip` had been deleted, saved the Redux files as the stock copy, so every later uninstall put Redux back. The install now stops before saving anything
* Fixed: Uninstalling Redux brought back the BepInEx folder but not the `winhttp.dll` that loads it, so mods silently stopped loading. The stock copy now keeps it
* Fixed: The patch downloads now finish before the install changes any file. Before, a dropped connection or a cancel during a full reinstall could leave you on stock KSP2 instead of the Redux version you had
* Fixed: The install checks again that KSP2 is not running once the downloads finish, so starting the game during a long download no longer gets it patched while it runs
* Fixed: When no chain of patches leads to the chosen version, the launcher now says so instead of reporting that Redux was installed
* Fixed: Installing a local patch file from Settings did nothing while offline, which is when it is most useful
* Fixed: Downloading KSP2 from Steam in Settings now makes that copy the active install, so Redux is not installed into another copy you already had

### Launcher

* Fixed: A crash or power cut while the launcher saved its settings could empty the settings file, and the next start then replaced every install profile and setting with defaults. Settings are now saved safely, and a settings file the launcher cannot read is kept as `redux-launcher-config.json.bak` before a new one is made
* Fixed: Updating the launcher failed on connections slower than about 21 Mbit/s, because the whole download had to finish within 60 seconds
* Fixed: The launcher no longer offers its own update while an install is running. Accepting it closed the launcher halfway through patching
* Fixed: Changing the version picker during an install could turn the Cancel button into Launch
* Fixed: Declining a launcher update now greys out Install straight away
* Fixed: Starting the launcher offline left the version list empty until a restart, and added an "invalid" entry to the channel list. Feeds and channels now fill in once a refresh reaches them, even if only one of them does
* Fixed: Picking a language in Settings left the language picker blank, so it looked like only English or Automatic could be chosen
* Fixed: Links inside news posts now open in your browser, including links relative to the post, and only web links are opened
* Fixed: A GitHub token added to the config for a private feed is now only sent to GitHub

### Command line tool

* Changed: Commands that change the launcher config, such as `installs add` or `settings set`, now ask you to close the launcher window first. The window keeps its own copy of the config and overwrote the change when it next saved
* Fixed: The command line tool wrote its logs as launcher logs, so a few commands pushed the launcher's own logs out. It now writes `cli-*.log` files, and `logs` always shows the launcher's log
* Fixed: "Files in use" and "not enough disk space" no longer tell you to uninstall and reinstall, since nothing was changed
* Fixed: `uninstall` now needs `uninstall.zip`, like the launcher, instead of failing partway through the restore without it
* Fixed: `launch` on Linux now asks you to turn on launching through Steam, like the launcher, instead of trying to run the Windows executable
* Fixed: `installs --json` now fills in `lastInstalledVersion`, which was always empty

If you are on macOS 12 or 13, decline this update and keep using launcher 0.6.3.8. This version does not open there.
