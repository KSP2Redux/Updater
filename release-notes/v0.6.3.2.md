# Launcher 0.6.3.2

* Fixed: With a Redux build from 0.2.9.0.105289 onward installed, the launcher could not read the installed version, so Launch and Update stayed greyed out. Those builds keep the game code in a different file, and the launcher now reads the version there as well as from older builds and stock KSP2
* Fixed: After verifying the game files over a Redux install, the launcher still could not read the version, so Redux could not be installed again. It now treats the restored game as stock
* Fixed: An install no longer starts while another program has game files open, such as a running KSP2 or a Unity project that uses the same KSP2 folder. Before, the install went ahead, failed on those files partway through and still reported that it had finished. Now it stops before changing anything and names the program to close
* Fixed: When converting the game's asset bundles fails, the install now fails and rolls back instead of reporting success with some bundles left unconverted. An uninstall that cannot put a bundle back now stops instead of losing track of it

If an earlier install finished with "Could not convert" lines in its log, close the program that had the game files open and install the build again.
