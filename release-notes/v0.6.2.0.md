# Launcher 0.6.2.0

A small one this time. If you have a fancy HDR monitor, you can now let KSP2 make use of it straight from the launcher, no more digging around in the game files.

## Launcher

* Added: An Enable HDR option in the Settings tab, next to Disable gfx jobs. It sets `hdr-display-enabled=1` in the game's `boot.config` for you
* Added: HDR is off by default, so nothing changes unless you turn it on. You need an HDR display with HDR turned on in your system's display settings for it to do anything

## Command line tool

* Added: `installs set --hdr on` or `off`, and `installs show` shows it
