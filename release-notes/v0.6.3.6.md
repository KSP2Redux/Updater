# Launcher 0.6.3.6

* Fixed: Installing a Redux build from before the URP port, or uninstalling Redux, could leave planets, the KSC, the main menu and other scenery magenta. Some game files had been converted to the URP shaders without the launcher keeping a record of it, so it could not put them back. The launcher now finds those files and downloads Steam's copies of them, using the Steam account you signed in with in the launcher
* Fixed: An uninstall or downgrade that could not put a converted file back no longer forgets about it. The launcher keeps a record of it until the file is restored
* Fixed (command line): `--install` now acts on the install it names. Before, commands such as `install` and `current` acted on the active install whatever `--install` said
* Added (command line): `bundles verify` and `bundles convert` list converted files the launcher has no record of

If the menu or the game shows magenta after installing an older Redux build, sign in with Steam in the launcher's settings and install the build again. If you are not signed in, the install stops and says so instead of leaving the game magenta.
