# Launcher 0.6.3.7

* Fixed: The Uninstall Redux button in Settings could leave planets, the KSC, the main menu and other scenery magenta. It deleted the launcher's record of the converted game files without putting those files back. It now puts them back first, the way the command line `uninstall` does, and shows its progress in the log on the Home tab. If a file cannot be put back, Redux stays installed and the launcher says why. It also stops with a message when the game is running
* Added: The launcher can show its text in other languages. This build has Japanese and Simplified Chinese, both only partly translated, and any text without a translation shows in English. By default it uses the system language when the build has it. Choose the language in Settings
* Changed: New installs added to the launcher start with no launch arguments. Before, they started with `-popupwindow`. Existing installs keep their arguments
* Changed: Installing now also writes texture overlays, which are smaller versions of the stock cloud textures that the game reads in place of the stock ones. The stock bundles are not edited for these textures, and uninstalling or reverting removes the overlays

If the menu or the game is magenta after you used Uninstall Redux in an earlier launcher version, install Redux again and then uninstall it with this version. The install finds the converted files and downloads Steam's copies of them, so you need to be signed in with Steam in the launcher's settings.
