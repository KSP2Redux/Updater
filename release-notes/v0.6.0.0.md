So this one has been cooking for a while. The launcher now runs on macOS, it can download KSP2 straight from Steam, and the command line tool can do everything the launcher can. Here is the full rundown.

## macOS support

KSP2 never came out on Mac, so the Mac launcher ships with its own open source Wine + DXMT runtime and runs the Windows version of the game through that. No CrossOver, no Whisky, no fiddling. Download the .dmg, drag it into Applications, download the game and press play.

- Apple Silicon only for now. DXMT turns Direct3D 11 into Metal, and it runs really well.
- The runtime needs Rosetta 2, which most Macs already have. If yours doesn't, the launcher tells you how to install it.
- The app is not signed by Apple yet, so macOS will complain the first time you open it. The steps to get past that are at the bottom. It's one button in System Settings, promise.

## Download KSP2 from Steam

You can now sign in with your Steam account in the launcher and download your own copy of KSP2, no Steam client needed. This is how you get the game on a Mac, since Steam refuses to download it there, but it works on Windows and Linux too.

- Sign in by scanning a QR code with the Steam Mobile App, or with your password and Steam Guard.
- You stay signed in between restarts. The Steam icon in the bottom right corner shows if you are connected. Click it to sign in, download the game or sign out.
- Downloads can be stopped and picked up later. It only fetches what is missing.
- You can only download it if you own it. Nice try.
- Your password is never saved. The login is kept in Windows data protection, the macOS keychain, or a file only you can read on Linux. Signing out also cancels it on Steam's side.

## Settings got a makeover

- Installs are now install profiles. Rename one with the pencil button next to the dropdown.
- The game path has a Browse button, so no more pasting paths like it's 2003.
- New Uninstall KSP2 button that deletes the game and its profile. Your saves are kept. If Steam manages that copy, the uninstall gets handed to Steam instead.
- You can now remove your last install too.
- Even spacing, and Enter or clicking outside a text field actually finishes editing it.
- Shorter labels so everything fits: "Disable gfx jobs" and "Launch via Steam". Launch via Steam is hidden on Mac since Steam can't run the game there anyway.

## First start fixes

- Starting with no installs left the launcher half loaded. Your fresh download wasn't selected and there were no release channels until you restarted. Fixed.
- The "download it now?" prompt no longer hides behind the main window.
- The disk space check on first install works properly and shows up as a dialog.

## Command line tool

redux-launcher-cli is now on par with the launcher:

- Runs on macOS and launches the game through the same Wine runtime and prefix as the launcher, so your saves are shared. `kill` stops it.
- `steam login`, `logout`, `status` and `download`. The QR code shows up right in your terminal.
- `installs show`, `installs set` and `installs delete` for the profile settings: game path, launch arguments, gfx jobs and launch via Steam.
- `settings` for patch source, concurrent chunks and verbose logging.
- `open install`, `open logs`, `open game-data` and `open storage` open those folders.
- `news` lists the latest posts.
- Self-update picks the Mac build on a Mac, instead of happily installing the Linux one.
