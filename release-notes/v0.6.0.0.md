# Launcher 0.6.0.0

This release brings the launcher to macOS with a bundled Wine runtime, adds signing in to Steam and downloading KSP2 from it on every platform, reworks the Settings tab around install profiles, brings the command line tool up to par with the launcher, and fixes startup stalling on hidden prompts.

## New Content

### macOS

* Added: A macOS launcher for Apple Silicon that runs the Windows version of KSP2 through a bundled open source Wine and DXMT runtime, with no CrossOver or other setup needed
* Added: A check for Rosetta 2, which the runtime needs, explaining how to install it when it is missing
* Added: Steps for approving the launcher the first time it opens, as it is not signed by Apple yet

### Steam

* Added: Signing in with Steam, by scanning a QR code with the Steam Mobile App or with a password and Steam Guard
* Added: Downloading KSP2 from Steam without the Steam client, which is the only way to get the game on a Mac. Downloads can be stopped and picked up later, and only a copy you own can be downloaded
* Added: A Steam indicator in the bottom right corner that shows the connection, and signs in, downloads or signs out when clicked
* Added: The saved sign-in is resumed in the background at startup

### Settings

* Added: Install profiles, renamed with a pencil button next to the profile dropdown
* Added: A Browse button for the game executable
* Added: An Uninstall KSP2 button that deletes the game and its profile while keeping saves, and hands copies managed by Steam over to Steam
* Updated: Even spacing between fields, and text fields finish editing on Enter or a click outside
* Updated: Shorter labels, "Disable gfx jobs" and "Launch via Steam", with Launch via Steam hidden on macOS where Steam cannot run the game

### Command line tool

* Added: A macOS build that launches and stops the game through the launcher's Wine runtime and prefix, so saves are shared
* Added: `steam login`, `logout`, `status` and `download`, with the QR code drawn in the terminal
* Added: `installs show`, `set` and `delete` for the profile settings: game path, launch arguments, gfx jobs and launch via Steam
* Added: `settings` for the patch source, concurrent chunks and verbose logging
* Added: `open` for the install, logs, game data and storage folders
* Added: `news` for the latest posts
* Improved: `doctor` lines up its values and reports the Wine runtime, Rosetta and the Steam sign-in

## Security

* Improved: The Steam sign-in is kept in Windows data protection or the macOS keychain, with a file only the current user can read on Linux. The password is never saved
* Improved: Signing out revokes the sign-in on Steam, not just on this computer
* Improved: The Steam login name is no longer written to the launcher log or shown by the CLI's `doctor`

## Bug Fixes & QoL Improvements

* Fixed: Startup stalling on a prompt that opened behind the main window, leaving installs unselected and no release channels until a restart
* Fixed: The disk space check on first install, which now shows as a dialog
* Fixed: The last install could not be removed
* Fixed: Delta patches for newly added directories

## Tools & Infrastructure

* Added: macOS CI jobs that build the Wine runtime, the app and the CLI, and attach the .dmg and the CLI to each release
* Fixed: The uploader failing to verify files because of GitHub raw URL caching
* Updated: Dependencies, including Avalonia
