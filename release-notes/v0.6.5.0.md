# Launcher 0.6.5.0

* New: A refreshed look in the spirit of Google's Material 3. Calmer buttons, with the ones that remove something outlined in red instead of filled, cards in Settings, even spacing on every tab, and a red ring that shows where you are when you move around with the keyboard. The black glass, Redux red and LED lettering are unchanged
* New: Interface motion. Tabs fade in, progress bars ease forward, buttons answer a press, and the main button glows when a launcher update is waiting. The **Motion** setting (it used to be "Background motion") turns all of it off
* New: Short confirmations, such as a finished uninstall or a copied report, now appear at the bottom of the window and go away by themselves instead of opening a dialog you have to close

### Installing

* New: Your saves and crafts are backed up before every install, update or uninstall. The five newest backups are listed in Settings under **Save backups**, and **Restore** puts one back, after backing up the saves you have now. KSP2 has to be closed to restore
* New: While patches download, Home shows the download speed and roughly how long is left, so a slow download no longer looks stuck
* New: The install log shows the time of each line, marks errors in red and the result in green, and stays quick with tens of thousands of lines. Select lines and press Ctrl+C (Cmd+C on a Mac), or use **Copy**, to copy them
* Fixed: Uninstall Redux, Install from patch file and Delete KSP2 in Settings could start while an update was running, so two jobs changed the same game folder. They now wait until the launcher is done and KSP2 is closed
* Fixed: Closing the launcher during an install stopped it halfway through a file and left the game half updated. The window now stays open until you cancel the install or it finishes
* Fixed: A download that timed out was reported as cancelled and never retried. It is now retried, and the other download mirror is offered as for any other failure
* Fixed: The free space check did not count every patch that is downloaded before the install starts, or the stock copy that is first built on your system drive, so a nearly full drive failed late with an unclear error. A download that cannot fit now fails at once instead of waiting forever
* Fixed: Patching a file needed about twice its size free, and a failed check could leave a temporary file in the game folder
* Fixed: A read-only file in the game folder could stop an uninstall or rollback halfway, and a damaged `uninstall.zip` is now caught before any file is deleted
* Fixed: A patch file chosen from your computer could name the game folder itself and delete all of it
* Fixed: **Delete KSP2** now refuses a drive root or a folder that also holds other programs or many other files, so a copy of the game unzipped into Downloads cannot take everything else there with it

### Launcher

* New: News posts in the sidebar show a short preview and mark the post you are reading, and the Community tab shows posts in a narrower column that is easier to read, with a link to the post on the website
* New: The Mods tab says mod support is on the way, with a button to the latest news, instead of being empty
* Fixed: News in other languages never loaded, because the site only has one feed. Every language now gets the news straight away
* Fixed: When the launcher could not reach the release feeds, for example with no internet, it asked to switch download mirrors every 5 minutes and the questions piled up. Only a refresh you start asks now
* Fixed: Starting the launcher while it was already open ran two copies, and whichever saved last threw away the other's settings. The second copy now closes
* Fixed: If the settings file was briefly locked, for example by an antivirus scan, the launcher replaced it with a new one and every install profile was lost
* Fixed: Copying to the clipboard could close the launcher when another program was holding the clipboard
* Fixed: A Steam sign-in or download that timed out looked like a cancel, and sign-in could stay stuck on "Working"
* Fixed: On macOS, the launcher froze for a moment several times at startup while it read the saved Steam login, and a Wine setup that failed the first time was never finished. It is now finished on the next launch
* Changed: **Copy Diagnostic Info** reads only the end of large logs, so it no longer freezes the window on a huge `Player.log`

### Support

* Fixed: On Windows, **Copy Diagnostic Info** copied an error instead of the recent log, because the launcher keeps its log open while it runs. The log is now included
* Changed: **Copy Diagnostic Info** now also reports every install profile with its launch settings and free disk space, the release feeds and whether they loaded, whether you are signed in to Steam, the download cache size, your system language, and on macOS the Wine runtime and whether Rosetta is installed. It adds the game data folder and the end of KSP2's own `Player.log`, shows your user folder as `~` so your name stays out of public bug reports, and confirms that it copied. Steam account names and launch arguments are never included

### Command line tool

* Fixed: Every command except `--help` and `--version` failed straight away with "The type initializer for LocalizationService threw an exception" since launcher 0.6.3.7. All commands work again
* Fixed: `installs delete ""`, or an empty `--install ""`, acted on the active install, so a script with an unset variable could delete or uninstall the wrong game. A blank name is now refused
* Fixed: `install --patch-file` with a file that does not exist removed Redux before it noticed. It now checks the file first
* Fixed: `install` and `update` now ask you to close the launcher window first, like the other commands that change the launcher config
* Fixed: `installs add .` saved a relative path that pointed somewhere else when run from another folder
* Fixed: With `--json`, a missing install, version or feed now prints a JSON error like every other failure, and an offline `update` exits with code 3 (feed unavailable)
* Fixed: `cache clear` reported success when some files could not be deleted
* Fixed: Offline, every command waited up to 5 seconds to check for a newer version of the tool
* Fixed: The Linux hint for turning on launching through Steam showed a command that did not work
