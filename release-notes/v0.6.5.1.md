# Launcher 0.6.5.1

### Installing

* Changed: The launcher no longer patches `boot.config` as a game file. It changes only the settings Redux needs and the graphics jobs option, keeps every other line, and never changes the build GUID. Installs with a different or edited `boot.config` are no longer refused
* Changed: Redux releases can now bring their own `boot.config` settings. Uninstall puts every setting the launcher changed back to its stock value, including settings an older launcher wrote
* Fixed: If an older launcher stopped during an update before it changed any game file, the launcher now undoes that update by itself instead of asking you to reinstall the game

Older launchers cannot read releases made for this version. Update the launcher before you update Redux.
