# Launcher 0.6.1.0

This release pimps the launcher a bit with a updated background and some visual effects. You can also now cancel the game directly from the launcher and optimized the application size and memory footprint. Ohh yes, before I forget, the beta channel is now called Snapshot.

### Launcher

* Added: A layered background with rendered stars and a subtle parallax effect that moves with your mouse.
* Added: A Background motion setting in the Settings tab to turn this off if you think its annoying or distracting. It is on by default for now.
* Added: A little surprise when you press the launch button...
* Added: While the game is running, the main button turns into a cancel button that stops/kills the game

### Command line tool

* Added: `settings set --background-motion on` or `off`, and `settings` shows it
* Added: `snapshot` is accepted anywhere a release channel is asked for

## Bug Fixes & QoL Improvements

* Fixed: Images in news posts were squished sideways in the narrow launcher. They now scale down and keep their shape
* Fixed: The update dialog cut the changelog off at 500 characters. It now shows all of it and scrolls, at the same size as before so you can view these long sexy changelogs
* Updated: The beta channel is now called Snapshot everywhere in the launcher and the command line tool
* Updated: The macOS download is now named `Ksp2Redux-macos-arm64.dmg`, matching the other downloads
* Updated: The launcher's images are now WebP, making the download about 3 MB smaller
